# Visual direction

Approved brief: recruitment-focused software engineering portfolio; English by default and Russian by switch; experimental interactive composition with a flame-colored accent.

## Tokens

- Background: #141413
- Primary text / light section: #eeede6
- Muted text: #aaa99f
- Border: #3b3b35
- Flame accent: #ff6138
- Flame highlight: #ffb18c
- Typography: self-hosted Manrope variable and IBM Plex Mono; system sans and monospace fallbacks.
- Gutters: clamp(24px, 5vw, 88px), 20–24px on mobile.

## Composition

Oversized, tightly tracked editorial typography; a generative 3D torus-knot reactor; a tilted orange marquee; numbered project studies; a warm light biography section; a recommendation; an oversized flame-colored contact close.

Each project gets its own conceptual SVG: orange decision flow, violet orbital discovery map, green geospatial clusters. Illustrations are never presented as product screenshots or verified architecture diagrams.

## Motion

Canvas responds to pointer position and rotates at a capped refresh rate. Pause outside viewport, on hidden documents, and when the user pauses motion. Reduced motion renders the static final composition. Scroll reveals are progressive enhancement; no blocking intro or scroll interception.

## Source of guidance

ui-ux-pro-max: verified portfolio result for `software engineer portfolio`, variance 9, motion 8, density 2. The initial FAQ-pattern result for the broader query was rejected. The final design adapts the relevant asymmetric typography and portfolio recommendations to the owner's explicit flame palette and interactive direction.
